# Market Compass

I would like to create a piece of software that will use AI to analyze global markets and invest money on my behalf with the aim of generating profit. The software should be able to make decisions about the optimal times to buy and sell assets and then execute these decisions independently. Initially, I would like the software to be able to run using a theoretical initial investment of £1000 to assess how well it performs before giving it access to real money. The AI should be able to invest in any area it assesses as likely to return a profit. Please allow me set the level of risk I am willing for the AI to accept. The AI should be able to base its decision making on previous patterns and trends in the markets, but also keep up to date with global events and factor in how these might affect market trends and values. The AI should never borrow or leverage assets. It should work on the assumption that it has a set amount given to it to invest at the beginning and will not receive any further money.
